The Construction Bijection

A new way to map graphs to integers through Matula trees

What if instead of encoding a graph's structure, we encoded how to build it?

Add vertices one at a time. For each new vertex, record which existing vertices it connects to. This sequence of choices becomes a number, and that number is a Matula tree.

Graph → Construction Sequence → Integer → Matula Tree

Building a Graph Step by Step

Consider the path graph P₄ with edges 0—1—2—3. We can build it by adding vertices in order:

c₁ = 1

●—●—●

●—●—●—●

Each cₖ is a bitmask: which of the previous k vertices does vertex k connect to?

Vertex Can connect to Choices Connection mask cₖ
v₁ {v₀} 2 choices (0 or 1) 1 bit
v₂ {v₀, v₁} 4 choices (00, 01, 10, 11) 2 bits
v₃ {v₀, v₁, v₂} 8 choices (000 to 111) 3 bits

The Canonical Sequence

Different vertex orderings produce different sequences for the same graph. The canonical construction is the lexicographically smallest one.

Why "canonical"?

Just as the canonical adjacency matrix is the lex-min over all vertex labelings, the canonical construction sequence is the lex-min build order. Isomorphic graphs get the same canonical sequence.

From Sequence to Integer

The sequence [c₁, c₂, ..., cₙ₋₁] encodes as a mixed-radix integer:

integer = c₁ + 2·c₂ + 2·4·c₃ + 2·4·8·c₄ + ...

This packs the variable-width masks into a single number. And here's the beautiful part: that integer is a Matula number, so it corresponds to a rooted tree.

The Swap: Path vs Star

Notice the highlighted rows. In the canonical encoding (upper-triangle minimum), the star comes before the path. But in the construction encoding, it's reversed:

Graph Canonical Encoding Construction Integer
Path P₄ 11 7 (smaller!)
Star K₁,₃ 7 (smaller!) 11

Why does the path come first?

The path is simpler to construct. Each vertex only connects to one previous vertex (forming a chain). The star requires the center vertex to connect to all previous vertices at once.

Path P₄: sequence [1, 3, 0] — the last vertex connects to nothing new
Star: sequence [1, 1, 1] — every vertex connects to the center

Three Ways to Order Graphs

Ordering What it measures Path vs Star
Canonical (upper-triangle) Matrix sparsity pattern Star < Path
Product (encoding product) Graph symmetry Star < Path
Construction Build complexity Path < Star

The construction bijection is the only one where paths come before stars. It measures how easy a graph is to build incrementally.
