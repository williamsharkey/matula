The Red Node Encoding

Graphs as Topology + Construction

Every graph can be decomposed into topology (how pieces connect) and construction (what each piece is). This worksheet lets you explore how graphs encode as Matula trees with a conceptual red node separating these two levels.

The Key Insight: A graph's block-cut tree shows how its 2-connected components (blocks) connect through cut vertices. This topology is itself a tree—encodable as a Matula number! Each block then has its own construction encoding.

Understanding the Encoding

Component What it represents Matula Tree Part
Topology Block-cut tree structure (how pieces connect) Nodes above the red level
Red Node Boundary between structure and content The transition depth
Construction What each 2-connected block actually is Nodes below the red level
Why "Red"? The red node is conceptual—it marks where meaning changes. Above it, we see how pieces fit together. Below it, we see what each piece is. It's like a scale boundary in a fractal: zoom out for topology, zoom in for construction.

Collision Analysis

Why collisions? The Matula tree doesn't distinguish connected vs disconnected when block constructions are similar. For example, "K₂ + isolated vertex" (disconnected) and "P₃" (two edges sharing a vertex) both give tree (o (o)).

Fix: Prefix encoding with (n, m) to guarantee uniqueness: M'(G) = cantor(n, cantor(m, M_tree))
