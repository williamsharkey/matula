The Sentinel Encoding

A collision-free graph invariant using a single extra bit

The Problem

The original upper-triangle encoding has degenerate cases:

Graph Encodings Product Problem
Empty₂ 0, 0 1 (empty product) All equal to 1!
K₂ 1, 1 1 × 1 = 1
Empty₃ 0, 0, 0, 0, 0, 0 1 (empty product)
Empty₄ 0, ..., 0 (24 times) 1 (empty product)

The Fix: Prepend a 1

enc' = 2k + enc

where k = n(n-1)/2 = number of edge positions

In binary, this just prepends a 1:

n k (edge positions) Original range New range (binary)
2 1 0 to 1 10 to 11 → [2, 3]
3 3 0 to 7 1000 to 1111 → [8, 15]
4 6 0 to 63 1000000 to 1111111 → [64, 127]
5 10 0 to 1023 10000000000 to 11111111111 → [1024, 2047]
The ranges don't overlap!
You can tell n just by counting the bits.

Why It Works: Proof Sketch

Step 1: Ranges separate by n
For n vertices: encodings ∈ [2k, 2k+1-1] where k = n(n-1)/2
For n+1 vertices: encodings ∈ [2k', ...] where k' = n(n+1)/2
Since k' > k+1 for n ≥ 2, the ranges don't overlap.
Step 2: Products separate by n
Max product for n = (2k+1-1)n!
Min product for n+1 = (2k')(n+1)!
Since k' > k+1 and (n+1)! > n!, products strictly separate.
Step 3: Within same n (Conjecture)
Different graphs → different encoding multisets → different products.
Verified computationally for n ≤ 5.
